# Hush Money

A co-op heist game for 1–4 players. Break in, clean out, get out.

**Website:** https://marci-glitch-ai.github.io/HUSHMONEY-FRIENDSLOP/

## Download

See **Releases** on the right, or use the website:

- **Mac (M1 or newer):** `HushMoney-Mac.dmg`
- **Windows 10 / 11:** `HushMoney-Windows-setup.exe`
- **In your browser:** https://hushmoney-server.onrender.com

## First launch

The game isn't signed yet, so the first launch needs one extra click:

- **Mac:** System Settings → Privacy & Security → **Open Anyway**
- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**

This repo only holds the downloads and the website.
